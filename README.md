# Liquorne — GitHub-only V5

Version sans backend, compatible GitHub Pages.

## Choix produit
Pas de fausse analyse IA de photo : sans backend, la reconnaissance fiable par image n'est pas réaliste.
Cette version utilise :
- photo comme illustration de fiche ;
- recherche obligatoire par nom ou marque ;
- détection code-barres si le navigateur le permet ;
- recherche OpenFoodFacts ;
- fallback Wikipedia ;
- base locale de quelques spiritueux connus ;
- validation utilisateur via résultats candidats.

## Déploiement
Uploader tout le contenu de ce dossier à la racine du dépôt GitHub Pages.

## Après mise à jour
Sur Android Chrome : Infos du site > Effacer les données, puis recharger.
